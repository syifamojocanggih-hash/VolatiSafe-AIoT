# HW-4.1 - Power gate GPIO25

Tanggal : 27 Okt 2026
Build   : pio run -e wokwi
Uji     : wokwi-cli . --timeout 180000 --scenario scenario_fault_range.yaml
Sumber  : docs/hardware/evidence/HW-4.3_scenario_fault_range_20261027.txt

## Yang dibuktikan

1. `power_begin()` menarik GPIO25 ke LOW sebelum inisialisasi kalibrasi/sensor.
2. Sensor hanya menyala selama sampling: `[PWR] sensor ON` -> `[PWR] sensor OFF`
   sebelum TX.
3. Tidak ada TX yang dimulai saat sensor masih ON.

Urutan di log:

```
[PWR] sensor ON
[SENS] adc ...
[PWR] sensor OFF
[SENS] m=... (nilai hasil konversi)
[TX] payload ...
[PWR] tidur 10 detik
```

## Kutipan log (siklus pertama)

```
=== VolatiSafe VS-SIM-001 | FW 1.0.0 ===
[PWR] wake: power-on/reset
```

## Batas bukti

Urutan dibuktikan dari log Serial simulator, bukan dari pengukuran arus.
Arus gate OFF (< 1 uA) dan perilaku MOSFET nyata baru diukur di HW-9.1 (F-05).
