HW-2.2 - Driver DS18B20 (11-bit, blocking) + klasifikasi suhu
Tanggal : 26 Okt 2026
Build   : pio run -e wokwi  (SENSOR_PROBE=1)
Skenario: scenario_a.yaml (suhu wajar), scenario_fault.yaml (di luar rentang)

Yang dibuktikan:
- DS18B20 terdeteksi di 1-Wire GPIO4 (bukan 0 device), jadi pull-up 4.7k
  dan pinMode INPUT_PULLUP sudah benar.
- Suhu 34.5 C -> status OK, nilai diteruskan apa adanya.
- Suhu 70.0 C -> status RANGE, nilai TIDAK di-clamp. Menyamarkan nilai rusak
  jadi angka wajar akan membuat data palsu lolos ke backend.
- Jalur putus (-127 C -> -999 / DISC) hanya bisa diuji di native test karena
  Wokwi tidak punya kontrol untuk memutus part; lihat unit_test_native.
